# Learnings

In this project, I learned the importance of automated 3D box selection for warehouse operations:

1. The Real-World Problem: When packing items manually, workers face two major issues:
   - If an item is too large and dimensions aren't checked, the item won't fit, causing warehouse delays.
   - If a small item (like a mug or book) is packed into an oversized box, the company wastes money on shipping costs and packing materials.

2. The Software Solution: Rather than relying on slow, manual guesswork, building an automated software system solves this by measuring dimensions and volume automatically, checking 3D rotation, and selecting the cheapest box that safely fits all items.

3. Working with AI: I also learned how to prompt AI concisely and effectively, communicate in a minimal yet clear way, and use tools like Antigravity efficiently to set up, test, and verify an end-to-end backend application.
